连接 Team Hub

开始使用 Team Hub

在本机连接 Antigravity、AGY CLI、AGY ACP、Claude Code 与 Codex 原会话协同工作。选择一种团队模式创建你的第一个 Team：

分工 Team 单工作区

绑定单一项目工作区，支持独立职位分工、动态 Hook 身份注入、多工作树同步与 AGENTS.md 规范治理。

无分工 Team 跨项目平级

不绑定工作区、不注入团队身份，适合多个独立项目的会话直接平级联调沟通。

流程：1. 创建 Team → 2. 部署工作区 Hook（或配置跨项目全局接入）→ 3. 新增成员并绑定原会话。提示：Codex 首次部署 Hook 后需在客户端设置中手动审批信任一次。
